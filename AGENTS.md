# Repository instructions

After each implementation change, including direct fixes without a separate spec/plan, update [the implementation record](docs/IMPLEMENTATION.md) and any affected documentation links.

Keep each fact in one authoritative place. For behavior already defined in a spec, record only its reference, implementation status and verification. Describe implemented behavior absent from the specs in the implementation record. If a description moves into a spec later, replace its record description with a link. README files and this file should point to those sources, not repeat their requirements or implementation details.

For requirements, current status, startup instructions and privacy rules, use [the documentation index](README.md).
