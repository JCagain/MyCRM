# People page layout amendment

This amendment follows the [People page batch-editing specification](MONICA-SPEC.md#batch-editing-and-interface). See the [implementation record](IMPLEMENTATION.md#people-page-layout-and-bulk-delete) for delivery status.

- Put **Include former memberships** next to the **Company** filter.
- Make **Add tags** and **Remove tags** equal-width dropdowns. Both controls should support selecting multiple tags.
- Add a bulk delete action for selected contacts on the People page.

To delete one person from their profile, use **Delete contact** near the bottom of the sidebar, below **Archive contact**.
