# Monica interface language amendment

This amendment extends the [Monica modification specification](MONICA-SPEC.md) and the [People page layout amendment](PEOPLE-PAGE-LAYOUT.md). See the [implementation record](IMPLEMENTATION.md#monica-interface-language) for delivery status.

Monica’s custom interface must support English and Simplified Chinese through its existing language preference under Settings. This covers People filters and bulk actions, work and contact editors, tags and ratings, and vCard import and review. Localize control labels, accessibility labels, status messages, validation messages, and import report reasons. Display contact names, company names, filenames, and other user-entered text as stored.
